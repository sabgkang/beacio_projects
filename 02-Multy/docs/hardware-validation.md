# 實體硬體驗收清單

此清單用於建置及自動化測試以外的驗收。沒有實際執行的項目不可標示通過；已完成燒錄及 USB 串列協定冒煙測試，其餘未勾選項目仍待實機驗證。

## 環境與接線

- [ ] 確認模組為 ESP32-S3 N16R8；開機 PSRAM／Flash 設定與模組相符。
- [x] 韌體燒錄成功，透過 USB-to-serial 連線，hello 能辨識正確裝置及版本（COM4；Multy-1446DA020F3C；1.0.0）。
- [ ] GPIO43／44 保留給 UART0；GPIO19／20 未用於目標介面。
- [ ] 所有目標採 3.3 V 邏輯並共地；I2C 各有外接上拉電阻。

## UART

- [ ] UART1：TX17 接 RX18；UART2：TX15 接 RX16。分別傳送並接收 00～FF，確認不附加 CR／LF。
- [ ] 切換 baud／資料位元／同位元檢查／停止位元，確認自動套用及回讀設定；5～7 資料位元測試資料需符合其位元寬度。
- [ ] 同時接收兩組 UART；修改目標設定不改變主機固定 115200 8N1。
- [ ] 使用已知外部 UART 裝置驗證，包含錯誤格式、突發流量及驅動溢位事件。
- [ ] 慢速 BLE 下資料遺失與錯誤計數可見，不保證高速無遺失擷取。

## I2C

- [ ] 兩組分別接已知裝置，確認 100／400 kHz、位址、原始 Write／Read。
- [ ] 邏輯分析儀確認每次操作均以 STOP 結束，不宣稱 repeated START 相容性。
- [ ] 不存在的位址回報 NACK，不觸發 GPIO 恢復。
- [ ] 安全地模擬 SDA 卡低／SCL 卡低及解除故障，確認恢復有界限且不重播寫入。
- [ ] 卡住的通道顯示 Recover bus，恢復後可使用，另一通道不受影響。

## SPI

- [ ] 各組 MOSI 接 MISO 做回接，確認 1～256 bytes 全雙工傳輸及 dummy read。
- [ ] 接已知裝置，驗證 Mode 0～3、MSB first 及各時脈選項。
- [ ] 以邏輯分析儀確認 CS 在完整交易期間為 LOW，成功／錯誤／斷線後為 HIGH。

## BLE 與 iPhone

- [ ] 廣播主要資料含自訂 128-bit Service UUID，scan response 含完整名稱，無截斷。
- [ ] PC Chrome／Edge 能搜尋、寫入及訂閱 Multy 自訂服務。
- [ ] iPhone Safari 在信任的 HTTPS 網址啟用 Beacio 後，可完成相同握手及六組介面操作。
- [ ] MTU 23／較大 MTU、256-byte 探測、相容模式重連及通知 ACK 正常。
- [ ] ACK 遺失、App 切背景、拔線、ESP32 重開機後，不重播未知結果的硬體命令。
- [ ] PC USB 與 iPhone BLE 競爭控制權、釋放、租期到期及交易中斷線，舊命令不跨世代執行。
